# MASTER GLOSSARY — LEVEL 9
*Definisi operasi untuk istilah struktur dan POI: lihat `02_TECHNICAL_VALIDATION.md §B`. Glosari Level 1–8 mengatasi definisi ini jika terdapat percanggahan.*

| Istilah | Maksud (BM) |
|---|---|
| **SOP** | Standard Operating Procedure: trading plan yang ditulis sebagai langkah berturutan, boleh diulang, direkod dan diuji |
| **Setup** | Gabungan konsep pada satu lokasi yang membentuk hipotesis trading |
| **Trading plan** | Peraturan entry, SL, TP, risiko, pengurusan dan keadaan no-trade |
| **Scalping / Intraday / Swing** | Gaya mengikut tempoh pegangan: pendek / dalam hari dagangan / berbilang sesi atau hari |
| **HTF / LTF** | Higher / Lower timeframe |
| **Bias** | Hipotesis arah (bullish / bearish / neutral) beserta syarat pembatalan |
| **Dealing range** | Julat antara swing high dan swing low yang dipilih untuk menilai Premium/Discount |
| **PDH / PDL** | Previous Day High / Low |
| **PWH / PWL · PMH / PML** | Previous Week / Month High / Low |
| **Session High / Low** | High/low sesi dagangan semasa atau terdahulu |
| **Liquidity sweep** | Harga melepasi aras liquidity kemudian ditutup semula di dalam julat |
| **Breakout** | Penutupan dan penerimaan harga di luar aras |
| **Execution zone** | Zon yang dipilih untuk entry selepas pengesahan, cth. FVG |
| **Aggressive entry** | Entry di POI tanpa menunggu pengesahan LTF |
| **Confirmation entry** | Entry selepas syarat pengesahan model dipenuhi |
| **Entry condition** | Syarat yang mesti benar sebelum order dihantar |
| **Invalidation** | Keadaan pasaran yang membatalkan tesis dagangan |
| **Stop-loss (SL)** | Order untuk menutup posisi apabila invalidation berlaku; harga isian tidak dijamin |
| **Buffer** | Jarak tambahan di luar aras struktur (tick, volatiliti, spread) |
| **Take-profit (TP)** | Sasaran keluar yang ditetapkan sebelum entry |
| **Partial take-profit** | Menutup sebahagian posisi di sasaran awal |
| **Breakeven (BE)** | Mengalihkan SL ke harga entry |
| **Trailing stop** | SL yang dialihkan mengikut struktur/jarak semasa harga bergerak |
| **Time-based exit** | Keluar selepas tempoh tertentu atau pada akhir sesi |
| **R** | Unit risiko: 1R = jumlah risiko yang dirancang bagi satu dagangan |
| **RR (Risk-to-Reward)** | Potensi ganjaran ÷ potensi risiko |
| **Planned vs realised RR** | RR rancangan sebelum entry vs RR sebenar selepas exit |
| **Win rate** | % dagangan yang menang |
| **Break-even win rate** | Win rate minimum supaya expectancy = 0 (sebelum kos) |
| **Expectancy** | Purata hasil setiap dagangan dalam R atau RM |
| **Profit factor** | Jumlah untung kasar ÷ jumlah rugi kasar |
| **Maximum drawdown** | Penurunan terbesar ekuiti dari puncak ke lembah |
| **MFE / MAE** | Maximum Favourable / Adverse Excursion semasa dagangan terbuka |
| **Slippage** | Beza antara harga dijangka dan harga isian |
| **Tick / tick value** | Pergerakan harga minimum / nilai RM bagi satu tick setiap kontrak |
| **Notional** | Harga × saiz kontrak (cth. 4,500 × 25 t = RM112,500) |
| **Initial margin** | Deposit untuk membuka posisi |
| **Maintenance margin** | Paras minimum ekuiti untuk mengekalkan posisi |
| **Intraday margin facility** | Kemudahan margin dikurangkan oleh broker bagi posisi yang ditutup dalam hari yang sama; **tidak mengubah risiko harga** |
| **Position sizing** | Pengiraan bilangan kontrak daripada bajet risiko dan jarak SL |
| **Backtest / Forward test** | Ujian peraturan pada data sejarah / dalam masa nyata ke hadapan |
| **Look-ahead bias** | Menggunakan maklumat masa depan yang belum tersedia ketika keputusan dibuat |
| **FCPO** | Crude Palm Oil Futures, Bursa Malaysia Derivatives (25 tan metrik; ⚠ sahkan spesifikasi) |
| **MPOB** | Malaysian Palm Oil Board |
