## SCENE 2 · 7.4 · WHAT IS DAILY BIAS (00:22–01:04)

- **Layout:** stack
- Heading — SUBTOPIC 7.4 · DEFINITION: “Daily Bias — a working hypothesis”.
- Cards: **Bullish bias** — Expect the day to favour higher prices / buy-side objectives (cue 2) · **Bearish bias** — Expect the day to favour lower prices / sell-side objectives (cue 2) · **Neutral bias** — No clear directional edge — wait or stand aside (cue 3).
- Cards: **Why before intraday** — Frames which intraday setups to study, and which to ignore (cue 4) · **Bias ≠ prediction** — A hypothesis — updated when evidence changes (cue 5) · **Bias ≠ confirmation** — Entry still needs lower-timeframe evidence (cue 6).
- **Beats:** (1) Daily Bias is a directional working hypothesis for the day. (2) A bullish bias expects the day to favour higher prices and buy-side objectives. (3) A neutral bias means there is no clear directional edge. (4) We set bias before intraday analysis because it frames which setups we study, and which we ignore. (5) But bias is not a guaranteed prediction. (6) And bias is not confirmation.
