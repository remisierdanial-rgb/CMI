  - Write the confirmation rule before the trade
  - VAGUE — "Enter when order flow looks bullish" — Cannot be tested. Will be applied differently every time. Invites hindsight.
  - TESTABLE (EXAMPLE) — Observable conditions — At a valid POI, after an SSL sweep: (1) one bar with Delta ≤ −400 and body ≤ 2 ticks; (2) within 3 bars, a close above the last swing high; (3) limit entry at that high; stop 2 ticks below the sweep low.

## Scene 8 — Common mistakes (4:17–4:45)

- **Template / layout:** `cards`
- **Transition:** 0.35 s fade-in; elements appear in sync with narration segments (fade / draw / pop); 0.25 s fade-out.
- **On-screen text:**
  - 9.4 · COMMON ORDER FLOW MISTAKES
  - Eight mistakes to avoid
  - 01 — Positive Delta = buy — Delta is not an automatic signal.
  - 02 — Negative Delta = sell — Passive buyers may absorb it.
  - 03 — Absorption = institutions — Identity is not visible.
  - 04 — DOM = executed volume — Displayed is not traded.
  - 05 — Ignoring classification — Know your provider's method.
  - 06 — Footprint without context — Location and structure first.
  - 07 — DOM shows all interest — Hidden and unsent orders exist.
  - 08 — Order flow from OHLC — Exact history needs tick data.

| # | Narration (EN, voiced) | Subtitle (BM, on screen) |
|---|---|---|
| 1 | Eight common Order Flow mistakes. | Lapan kesilapan biasa Order Flow. |
| 2 | Treating positive Delta as an automatic buy signal, or negative Delta as an automatic sell signal. | Menganggap Delta positif sebagai isyarat beli automatik, atau Delta negatif sebagai isyarat jual automatik. |
| 3 | Assuming all absorption is institutional, and confusing displayed order-book quantity with executed volume. | Menganggap semua absorption adalah institusi, dan mengelirukan kuantiti order book yang dipaparkan dengan volume yang dilaksanakan. |
| 4 | Ignoring the provider's classification method, and using the footprint without understanding price context. | Mengabaikan kaedah klasifikasi provider, dan menggunakan footprint tanpa memahami konteks harga. |
| 5 | Assuming the DOM represents all market interest, and using ordinary candles to claim exact historical order-book behaviour. | Menganggap DOM mewakili semua minat pasaran, dan menggunakan candle biasa untuk mendakwa tingkah laku order book sejarah yang tepat. |
