## Scene 7 — Walk-forward (3:38–4:17)

- **Template / layout:** `viz`

- **Transition:** 0.35 s fade-in; elements appear in sync with narration segments (fade / draw / pop); 0.25 s fade-out.
- **On-screen text:**
  - 15.4 · WALK-FORWARD
  - Train, test, roll forward
  - Optimise on a training window, then test on the next unseen testing window
  - Roll both windows forward and repeat
  - Join all test windows → an out-of-sample record
  - Parameter stability: do chosen settings jump around between windows?
  - Reveals behaviour across regime changes
  - Limitations: Results depend on window lengths; needs long data; more computation; still historical and still vulnerable if the whole process is repeated many times.
